# LoanFi - DeFi Loan Aggregator

A "Pay with Klarna" button for crypto checkouts. Merchants embed the widget, users see loan options from DeFi pools (Aave, Compound), pick their terms, and complete purchase with borrowed funds.

## Features

- Real-time loan options from Aave & Compound
- Embeddable widget for merchants
- Multi-chain support (Base, Arbitrum, Ethereum, Polygon, Optimism)
- Admin CLI for management
- Live price feeds (Chainlink + CoinGecko)

## Tech Stack

- Next.js 16 + TypeScript
- PostgreSQL + Prisma
- Viem + Wagmi (blockchain)
- RainbowKit (wallets)

## Quick Start

```bash
npm install
npm run db:migrate
npm run db:seed
npm run dev
```
